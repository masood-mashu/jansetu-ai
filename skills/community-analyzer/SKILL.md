# Community Analyzer Skill

## Workflow
1. **Parse & Normalize:** Ingest natural language query, voice transcription, or sensor telemetry.
2. **Geospatial & Demographic Mapping:** Correlate request location to district, ward, and census vulnerability index.
3. **Priority Scoring:** Calculate urgency based on impact severity, population affected, and duration of issue.
4. **Action Formulation:** Output prioritized action recommendations with resource allocation estimates.
